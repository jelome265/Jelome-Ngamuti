# Jelome Ngamuti — Portfolio

This repository is being rebuilt from a documented design direction before implementation.

**Direction:** clean, medieval-inspired, professional. The medieval character should come from typography, geometry, and restrained detailing—not fantasy decoration or reduced readability.

**Frontend:** React + TypeScript (TSX), Vite, and Tailwind CSS v4. The latest release verified for this planning baseline is 4.3.3 (23 October 2026). Use the latest stable release when implementation begins and commit the lockfile.
